# G5 控制器仿真报告

在 30 Hz、速度内环时间常数 0.10 s 的模型中，建议先试 **位置增益 `Kp = 3 s⁻¹`、航向增益 `Kh = 3 s⁻¹`**。相对于仿真基线 `1 / 1`，MARK 最慢换向恢复时间由 1.63 s 降至 0.97 s，TAG 对准由 2.57 s 降至 0.90 s。候选增益下，±0.05 和 ±0.10 m/s 的恒定前馈偏差分别留下约 16.7 和 33.3 mm 的沿轨稳态位置误差。

## 模型与验证

独立构建已验证 `43ac999` 修复了 `smoothed_yaw()` 重复定义。基线增益下的 TAG 对准和后退闭环均收敛，确认位置环和航向环的反馈方向与车体系约定一致。[滤波器声明](../include/controller/yaw_filter.hpp#L22) · [控制律实现](../src/controller.cpp#L34)

选择 `τ = 0.10 s` 作为 C 板速度内环起步模型，约等于 30 Hz 下的三个帧周期，阶跃在 0.10 s 时达到目标速度的约 63%。线速度和角速度使用同一时间常数。仿真采用真值车速反馈、无噪声位置和朝向、MARK 端点瞬时反向、无执行器限幅和附加通信时延。阈值、轨道尺寸与初始偏差由测试定义。实车的内环响应与兑换机构参数待实测。背景、误差带和运行命令见 [测试说明](../tests/README.md)。

GNU C++ 13.3.0、CMake 3.28.3 下，独立构建和严格 C++17 的 Release 构建均通过 6 项 CTest。另验证 `BUILD_TESTING=OFF` 和父工程嵌入两种构建方式都只构建控制器库。

## 前馈偏差与兑换位置余量

`Kh = 3 s⁻¹`，恒定速度偏差沿世界系轨道正方向注入。测量最后一次负向段和正向段各自最后 1 s 的带符号位置均值。正偏差让车在轨道正方向走得偏多，因此用「目标相对位置减期望相对位置」定义的残差为负。

| 速度偏差 (m/s) | Kp=1 负向段 (mm) | Kp=1 正向段 (mm) | Kp=3 负向段 (mm) | Kp=3 正向段 (mm) |
| ---: | ---: | ---: | ---: | ---: |
| −0.10 | +99.764 | +100.236 | +33.333 | +33.333 |
| −0.05 | +49.764 | +50.236 | +16.667 | +16.667 |
| 0 | −0.236 | +0.236 | ≈0 | ≈0 |
| +0.05 | −50.236 | −49.764 | −16.667 | −16.667 |
| +0.10 | −100.236 | −99.764 | −33.333 | −33.333 |

测量期间，相对速度峰值在 `Kp=1` 时为 0.444 mm/s，在 `Kp=3` 时低于输出分辨率 0.001 mm/s。此时 P 项平衡前馈偏差，残差与 `e_steady = −bias / Kp` 一致。这组实验量化了相对速度接近零时仍存在的沿轨偏差。

以可分给 G5 稳态沿轨误差的单侧预算 `B` 计，在 `Kp=3` 下，±0.05 m/s 需约 **16.7 mm**，±0.10 m/s 需约 **33.3 mm**。若 `B = 20 mm`，前者会用掉约 83% 的位置预算，后者单项即超预算。无偏差换向时仍测到 60.25 mm 的动态位置峰值，匀速结果只适用于换向恢复后的时段。实际 `B` 需要依据净开口、矿石有效宽度及外参、时延和释放误差确定。评估积分项时，可将实测的前馈偏差和剩余沿轨位置预算与这组残差对照。
